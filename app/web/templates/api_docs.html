Pourquoi cette page n'est pas le Swagger habituel

La documentation intégrée de FastAPI charge ses styles et son script depuis un CDN. La politique de sécurité de cette application n'autorise que ses propres ressources : la page s'affichait donc entièrement blanche. Plutôt que d'assouplir la sécurité pour afficher une page, elle est reproduite ici à partir du schéma de l'application.

Le schéma reste disponible pour les outils externes : /api/openapi.json — il s'ouvre dans Postman, Insomnia ou tout générateur de client.

Toutes les routes de lecture sont en GET. Les routes de modification exigent l'en-tête X-CSRF-Token et sont refusées en mode consultation.

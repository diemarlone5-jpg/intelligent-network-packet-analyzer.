La base grossit à chaque capture

Une capture qui tourne enregistre les sessions, les communications et les paquets. Rien n'est supprimé automatiquement : au bout de plusieurs heures, la base peut occuper plusieurs centaines de mégaoctets et ralentir le démarrage.

Rien n'est effacé sans que vous le demandiez. La purge ci-dessous supprime un nombre explicite de sessions, en gardant les plus récentes.

Ce que cette page ne montre pas, volontairement

Aucun secret n'est affiché. Les clés d'API, le jeton Supabase et la clé de signature restent dans le fichier .env, qui n'est jamais enregistré dans Git. Cette page indique seulement s'ils sont fournis — jamais leur valeur. Une page de paramètres ne doit pas devenir un moyen de lire les secrets d'une installation.

La configuration se modifie dans le fichier .env, puis en redémarrant l'application. C'est volontaire : une interface web qui modifierait les réglages du moteur pourrait être détournée, et la configuration resterait alors invisible dans le projet.
